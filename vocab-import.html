Vocabulary Import Helper

This page turns a pasted word list into properly formatted entries for data/vocabulary.js. It doesn't save anything automatically — it just generates text for you to copy and paste into the file yourself. Nothing here is shown to students; it's a convenience for building new chapter lists.

1. Choose a paste format

Paste one word pair per line. Separate Latin and English with a tab or a comma (a Quizlet plain-text export using tabs works directly).

First row must be a header using these column names (any order, extras ignored): latin, english, pos, gender, declension, conjugation, chapter, notes. Only latin and english are required.

2. Copy into data/vocabulary.js

Paste the block below inside the window.VOCAB_DATA = [ ... ] array in data/vocabulary.js — right before the closing ];. Double-check the generated chapter, pos, and any macron spelling before saving.
